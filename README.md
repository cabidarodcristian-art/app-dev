# F.R.I.E.N.D.S (1994–2004)

**F.R.I.E.N.D.S** is an iconic American television sitcom created by *David Crane* and *Marta Kauffman*. Set in Manhattan, New York City, the series follows the personal and professional lives of six twenty- and thirty-something best friends navigating romance, career struggles, and adulthood together.
